03

Information architecture

One st.navigation app, four pages, global quarter picker, query-param deep links so every row is a shareable URL. All current functionality maps in — nothing dropped.

SIGNALS · home

Consensus buys · crowded exits · new-stakes tape · quarter metrics. Replaces "Overview".

/?q=Q1_2026

MANAGERS

Roster grid → profile: book, weights, QoQ changes, options overlay. Absorbs "Portfolio Analysis" incl. multi-manager overlap.

/?page=manager&id=situational-awareness

SECURITIES

Ticker search → holders, entries/exits, ownership. Replaces "Securities Detail" + ticker filter.

/?page=security&t=MSFT

SCREENER

The full sortable table with every current filter + CSV export in real dollars. Replaces "Top Holdings".

/?page=screener&min_holders=5
